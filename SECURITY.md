# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes, with vigilance |
| Earlier greetings | Regrettably not |

## Reporting a vulnerability

If you discover a security issue, open a private report with a clear reproduction path. If you discover an extra `l`, use the incident runbook instead; that is not a vulnerability, it is a cultural emergency.

## Security posture

The application accepts no input, stores no customer data, and performs no authentication. This is an intentionally narrow attack surface supported by several documents.
